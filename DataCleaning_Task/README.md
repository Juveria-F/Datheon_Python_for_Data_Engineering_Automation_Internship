# Automated Data Cleaning Script

## Project Description
This project uses Python and Pandas to automatically clean and validate a dataset.

## Technologies Used
- Python 3
- Pandas
- CSV

## Features
- Handles missing values.
- Normalizes currency formats.
- Standardizes date formats.
- Removes duplicate records.
- Validates dataset schema.
- Identifies invalid records.
- Generates automated data quality reports.

## Input File
raw_data.csv

## Output Files
1. cleaned_data.csv
2. rejected_records.csv
3. quality_report.txt

## How to Run

Install Pandas:

```bash
pip install pandas
```

Execute:

```bash
python clean_data.py
```

## Result
Successfully cleaned and validated the dataset and generated output files and a data quality report.
